═══════════════════════════════════════════════════════════════════════════════
🎯 WHAT THE SYSTEM DOES
═══════════════════════════════════════════════════════════════════════════════

USER FLOW:
1. Open browser → http://localhost:3000
2. Paste news headline/article in text box
3. Click "Analyze with AI" button
4. System processes text (2-3 seconds)
5. Results display:
   - Verdict: "REAL" or "FAKE"
   - Confidence: 0-100%
   - Model: "Sklearn TF-IDF + Classifier"

BEHIND THE SCENES:
1. Frontend sends POST request to /predict endpoint
2. Backend receives text
3. TF-IDF vectorizer transforms text into numbers
4. Logistic Regression classifier predicts
5. Result returned to frontend
6. UI displays verdict + confidence

🚨 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════════

Issue: "Port 8000 already in use"
Fix:   netstat -ano | findstr :8000
       taskkill /PID <PID> /F

Issue: "Port 3000 already in use"
Fix:   netstat -ano | findstr :3000
       taskkill /PID <PID> /F

Issue: "pnpm not found"
Fix:   npm install -g pnpm

Issue: "Module not found"
Fix:   cd D:\Fake_news_Detection
       pnpm install
       .\.venv\Scripts\python.exe -m pip install -r server/requirements.txt

Issue: "Cannot load model"
Fix:   Verify files exist:
       - model/fake_news_model.pkl
       - model/fake_news_vectorizer.pkl
