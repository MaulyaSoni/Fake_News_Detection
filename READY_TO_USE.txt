🔧 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER INTERFACE (Next.js React - Port 3000)
   ↓
   User pastes news text and clicks "Analyze with AI"
   ↓
2. API REQUEST (Frontend sends text to backend)
   ↓
   POST http://127.0.0.1:8000/predict
   Body: { "text": "..." }
   ↓
3. ML PREDICTION (FastAPI + Python - Port 8000)
   ↓
   ├─ Vectorize text using TF-IDF (from pickle)
   ├─ Run through Logistic Regression classifier
   ├─ Get probability scores
   └─ Return verdict: "REAL" or "FAKE"
   ↓
4. RESPONSE
   ↓
   Returns: { verdict, confidence, modelName }
   ↓
5. UI DISPLAYS RESULT
   ↓
   Shows verdict badge + confidence percentage
